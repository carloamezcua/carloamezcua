## 👨‍💻 About Me

I am an **Artificial Intelligence and Data Science** undergraduate currently in my **5th semester** at Universidad de Guadalajara (CUGDL), with strong analytical foundations acquired through prior university studies in **Physics and Mathematics** (CUCEI). 

My technical focus bridges **High-Performance Backend Engineering**, **Distributed Data Pipelines**, and **Applied Machine Learning**:
* 🏗️ **Backend & Systems:** Designing decoupled, asynchronous RESTful APIs with **FastAPI**, **Pydantic**, and **MongoDB Atlas (Motor)**, isolating CPU-intensive workloads from the event loop using `asyncio.to_thread`.
* 🌊 **Data Engineering & Lakehouse:** Building resilient ETL/ELT pipelines following the **Medallion Architecture (Bronze $\rightarrow$ Silver $\rightarrow$ Gold)**, orchestrated via **Prefect DAGs**, with out-of-core processing via **Dask** and high-speed columnar storage in **Apache Parquet / PyArrow**.
* 🧠 **Machine Learning & AI:** Full-cycle development from exploratory data analysis and feature engineering (clustering) to model training (**Scikit-Learn**, **PyTorch**), model serving (**Streamlit**, `joblib`), and research documentation in **LaTeX**.
* ⚡ **Systems & Concurrency:** Deep understanding of OS-level execution, Python GIL behavior, thread-safe synchronization (`Lock`, `Semaphore`, `Queue`), and containerized worker pools with **Docker Compose** and **Redis**.
* 🌐 **Bilingual Communicator:** Full working professional proficiency in English (B2+/C1) and native Spanish, backed by corporate experience in technical data auditing and platform incident operations.
